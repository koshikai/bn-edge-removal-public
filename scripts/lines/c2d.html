旧 C2D / BBM

一部閉鎖。同じ生物機構の粗いモデルから細かいモデルへ制御知識を移す。軸A はノード介入、軸B は不可逆の辺除去。軸B の学習路線は2026-10-11に閉じた。

閉じた（軸B の学習路線、2026-10-11）一部閉鎖exploratory

01問い

閉じた このラインの問いは、粗いモデルで得た制御知識を、同じ生物機構の細かいモデルへ移せるか、である。粗から細への転移（coarse-to-detailed transfer）と呼ぶ。粗いモデルで学んだ制御が細かいモデルでも通じれば、細かいモデルで最初から学ぶ手間を減らせる。

移し方は2つの軸に分けた。軸A はノードへの介入を移す。軸B は不可逆の辺除去を移す。行動の種類が違うので、2つの軸の結果は別々に読む。

軸B で「学習によって転移の優位を示す」路線は、2026年10月11日に閉じた。軸A の結果は記録として残っている。どちらの数値も、現在進んでいるラインの結果ではない。

03介入の意味

exploratory 軸A のノード介入は、ノードの値そのものを動かす。どのノードに介入するかを、粗いモデルの知識から選ぶ。介入の細かな形（固定する時間や値の決め方）は、このページの資料に無い。

軸B の不可逆の辺除去は、ノードの値ではなく、ノードの間の辺を無効にする。一度除去した辺は戻せない。だから、どの順で除去するかが結果を左右する。

軸A：x_v ← 介入で決めた値　　軸B：辺 (u→v) を除去し、以後ずっと戻さない

具体例で言うと、軸A では「ノード v を動かす」が1つの行動になる。軸B では「辺 u→v を除去する」が1つの行動で、その行動はやり直せない。同じ生物ペアでも、2つの軸は選べる行動の集合が違う。だから成功率の意味も違う。

他のラインとの違い。設定 A/B も小さいモデルから大きいモデルへ知識を移す。このラインは、合成した BN ではなく、同じ生物機構を粗さの違う2つのモデルで書いたペアを使う。

04実験の手順

  1. 対応づけを作る。粗いモデルと細かいモデルのノードを、明示的に結ぶ。対応づけには、高信頼の部分集合と、整えた全対応（curated full）の2通りがある。plan.md:462@f438ede0
  2. 蒸留する（軸A）。教師の制御を、対応づけを通して GNN へ蒸留する。評価は n=30で、seed を3つ使う。document/09_coarse_to_detailed_transfer.md:123@f438ede0
  3. 比べる対象を置く。教師そのもの、乱択、対応づけを使わないゼロショットを並べる。ゼロショットは15 run で評価した。plan.md:198@f438ede0
  4. 検証器で測る。到達、到達と維持、basin の代理指標の3層で測る。plan.md:464@f438ede0
  5. 軸B では判定を2段にする。ラベル集合を凍結し、主段で5 seed のうち3 seed の合格を求める。主段を通れば確認段階へ進む。document/46_axisb_learning_line_closure_2026-10-11.md:115@f438ede0
  6. 適応の効果を確かめる（軸B）。合格した構成について、転移腕がゼロショットより上かを見る。同じ値やそれ以下なら、適応の効果はないと数える。document/46_axisb_learning_line_closure_2026-10-11.md:157@f438ede0

除外規則と実行時間は、このページの資料に無い。

05指標の定義

exploratory 成功率は、目標を満たした試行の数を、評価した試行の数で割ったものである。軸A の蒸留の比較では分母が30である。3 seed の結果は、平均と seed ごとの値を両方書く。

成功率 = 目標を満たした試行の数 ÷ 評価した試行の数（軸A は30）

到達（reach）は、目標の状態にいつか着いたかを見る。到達と維持（stay-k）は、着いたあと k ステップ目標に留まったかまで見る。basin の代理指標（basin-proxy）は、目標の吸引域（basin）に入ったかを近似で見る。k の値と近似の作り方は、このページの資料に無い。

差は「ポイント」で書く。ポイントは2つの成功率の差で、比ではない。ゼロショットの −46.7ポイントは、15 run の記録である。

到達で測るか、維持まで測るかで、同じ制御の成績は大きく変わる。このラインでは、成功率を読むときに、どの層の値かを必ず確かめる。

07内訳と副次

exploratory 対応づけの質が成績を変える。高信頼の部分集合を使うと86.7%で、整えた全対応の73.3%を上回った（n=30）。cIAP と BAX を単純に落とす変更や、BCL2 を戻す変更では改善しなかった。信頼度の低い相互作用どうしが影響し合っていることを示している。

plan.md:462@f438ede0

到達だけでなく維持まで見ると、成績は大きく下がる。stay-k の値は apoptosis で72%、MAPK で7.2%だった。basin-proxy は MAPK で14.5%だった。MAPK では、維持まで満たす試行が少ない。

plan.md:464@f438ede0

この低下は、到達の数値だけを見ていると見えない。蒸留の93.3%と stay-k の72%は、層が違う値なので、差を取って比べない。どの値も、どの層の検証器で測ったかと一緒に読む。

軸B では、凍結したラベル集合の正例が少なかった。main 層のラベル集合は全7176行で、支持が非空の正例は90行だけである。学習で転移の優位を示せる範囲は、もともと狭かった。

09読むときの注意

2軸の成功率を同じ順位表に並べない。軸A のノード介入と軸B の辺除去は、選べる行動の集合が違う。

閉じた数値を、現行ラインの結果として引用しない。軸B の記録は主張を立てない exploratory の記録である。

93.3%は到達の層の値で、apoptosis の1組だけのものである。維持まで見た値（stay-k）とは別に読む。

区間や検定の記録が無いので、蒸留が教師や乱択より「優位」とは書かない。
