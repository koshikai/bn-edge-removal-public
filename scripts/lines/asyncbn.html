LINE 05 · 定理と評価

非同期 BN

非同期更新の下で、辺の mask とその保持時間を観測ごとに選ぶ。

exactempirical

01問い

非同期に更新するネットワークで、辺の mask をいつまで保つかを状態で選ぶと、差が出るか。また、目標の固定点を保ったまま切れる辺はどれか。

02モデルと規模

  • 各マイクロステップで、確率に従って1ノードだけ再計算する。
  • 評価は 94 ネットワーク（n=50 が 46、n=100 が 48）を使う。

03何を動かすか

辺の mask と、その保持時間 T を動かす。観測のたびに両方を選び、T マイクロステップ同じ mask を使う。次の観測で mask を戻せる。

04実験の設計

  • 94 ネットワーク × 初期状態3 × 制御器3 × 重み5 = 4230 エピソード。
  • 制御器のうち2つは、保持時間を状態依存にするものと、mask だけを変えるもの。
  • 判定は費用を見る前に固定した（事前登録）。

05結果

exact 定理

目標が固定点で、残る辺のグラフが自己ループを含めて DAG であるとする。このとき、x*j = 0 の辺を除去しても、その固定点を保てる。

目標 x* が固定点 ∧ 残る辺のグラフが DAG（自己ループを含む）
⇒ x*_j = 0 の辺の除去で x* を保てる

これは十分条件で、必要条件ではない。

empirical 評価

4230 / 4230完走したエピソード
5 / 5保持時間を状態依存にする制御器：平均差の 95% 区間が 0 を除いた重み
0 / 5mask だけを変える制御器：同じ
  • 完走は 4230/4230。
  • 保持時間を状態依存にする制御器は、5つの重みすべてで平均差の 95% 区間が 0 を除いた。例：W1 で −1839.23、区間 [−2719.88, −1107.84]。
  • mask だけを変える制御器は 0/5。

06読むときの注意

定理（exact）と評価（empirical）は別の結果である。評価の数値で定理を裏づけたことにはしない。

先行研究に同じ定理がある。このラインの新しい主張として読まない。

判定は費用を見る前に固定した（事前登録）。
