LINE 05 · 定理と評価

非同期 BN

定理と評価の両方。非同期更新の BN で、辺の除去を保持時間つきのマスクとして選ぶ。

定理は exact評価は empirical十分条件だけ

01問い

exact このラインの問いは2つある。非同期更新の下で、辺の除去をどう意味づけるか。除去した辺を、いつ戻すか。同期更新では全ノードが同時に動くが、非同期では1回に1ノードしか動かない。だから「どの辺を切るか」に加えて「どれだけの間切っておくか」が制御の中身になる。

このラインは制御を、マスクと保持時間の組として扱う。観測のたびに、許された辺の部分集合（マスク）と保持時間 T を選ぶ。同じマスクを次の T マイクロステップの間かけ続け、次の観測で選び直す。マスクは次の観測で戻せると仮定する。

ページは定理と評価に分かれる。定理の部分は exact、評価の部分は empirical である。定理は目標へ着くことを保証する十分条件を与える。評価は、その保証の下でどの制御器の費用が低いかを測る。

02設定

exact 状態は x ∈ {0,1}n、目標は x* である。各マイクロステップで、固定の確率 p_i に従ってノード i を1つだけ選ぶ。p_i は正で、和は1である。選ばれたノードの値だけを再計算する。

制御に使うマスクは、x* を固定点のまま保たなければならない。つまり、どのマスクをかけても x* は吸収状態である。一度 x* に着けば、その後どのマスクを選んでも離れない。

03介入の意味

exact 辺 j→i の除去は、規則 i の中で x_j に当たる入力だけをリテラル0に置き換える。その入力が NOT の下で使われていても0を入れる。始点 j の値と規則は変わらない。

f_i′(x) = f_i(x) |x_j の入力 = 0

仮の例で書く。f_i = x_k AND NOT x_j のとき、j→i を除去すると f_i′ = x_k AND NOT 0 = x_k になる。抑制がなくなり、i は x_k だけに従う。f_i = x_j OR x_k なら、f_i′ = x_k になる。この例はモデルの実際の規則ではなく、式の読み方を示すためのものである。

同期更新との違いは、置き換えた規則が使われる時刻にある。同期更新では、マスクをかけた次の時刻に全ノードが新しい規則で動く。非同期更新では、ノード i が選ばれたマイクロステップでだけ f_i′ が使われる。どのマイクロステップで i が選ばれるかは確率 p_i で決まる。だから、同じマスクでも保持時間 T によって効果が変わる。

他のラインとの違い。SF + GPI のラインは抑制辺に1を代入し、抑制が常にかかる状態にする。このラインは NOT の下でも0を入れるので、抑制が消える。どちらも「辺の除去」と呼ばれるが、抑制辺での意味が逆になる。

04実験の手順

exact 手順の1〜3は定理、4〜6は評価である。定理の部分は十分条件で、必要条件ではない。

  1. フォールバックを作る。x* が元の BN の固定点であるとする。許された除去可能辺のうち、x*_j = 0 の始点から出る辺をすべて切ったものを u_B とする。残る辺のグラフが、自己ループも閉路として数えた上で DAG なら、u_B は x* を固定点のまま保ち、大域的にほとんど確実に（almost surely）安定化するフォールバックになる。README.md:17@bb1fa91
  2. ポテンシャルを作る。DAG の逆順に a_j = 1 + Σ a_i（残る辺 (j,i) について）を定め、w_j = a_j / p_j とする。ポテンシャルは V(x) = Σ w_i 1{x_i ≠ x*_i} である。この重みは厳密な有理数だが、グラフの深さに対してビット長が指数的になりうる。README.md:19@bb1fa91
  3. 受理規則を課す。提案した組 (u, T) について、x* が不変であることと、T マイクロステップ後の V の期待値の上界 U_T が U_T ≤ V − 1 を満たすことを求める。満たさないときは u_B を1マイクロステップだけかける。T に上限があるので、ほとんど確実に吸収され、期待到達時間は E[τ] ≤ T_max V(x_0) / ε（ε は受理規則の減少幅）で抑えられる。README.md:21@bb1fa91
  4. 制御器を3つ用意する。基準は22個の候補から選ぶ STC22 である。仮説 B は候補を200個に増やした STC200、仮説 A は同じ22個の候補の上で先読みをする LA22 である。docs/decisions/ADR-004.md:5@bb1fa91
  5. 判定条件を固定する。費用を見る前に、Δ の平均の95%区間の上限が0未満であることを判定条件として固定した。5つの重みは同じネットワークを共有し、多重性の補正はしない。prereg/Headroom_2026-10-29.md:64@bb1fa91prereg/Headroom_2026-10-29.md:67@bb1fa91
  6. 実行して集計する。94 ネットワーク × 初期状態3 × 制御器3 × 重み5 の 4230 エピソードを実行した。実行する組はすべて厳密に再認証した。docs/Headroom_eval_report_2026-10-30.md:11@bb1fa91

除外規則。フォールバックがないモデルは失敗として記録し、都合のよいモデルに置き換えない。すべてのモデルが最後の段階まで進む必要はない。

05指標の定義

exact エピソードの費用 J_w は4つの項の和である。観測の回数、辺の時間、切り替えの回数、経過時間 τ に、それぞれ重みを掛ける。

J_w = c_o·観測数 + c_e·辺時間 + c_s·切替数 + c_t·τ

重みは w = (c_o, c_e, c_s, c_t) の5組で、単位は「辺1本を1マイクロステップ除去する」を1とする。分母はなく、エピソードごとの合計である。

差 Δ は、各ネットワークで制御器 X の費用を基準 STC22 と比べたものである。ネットワークごとに平均をとり、それをネットワーク全体で平均する。分母は94ネットワークである。負なら X の費用が低い。

Δ = J(X) − J(STC22)　　相対差 = (J(STC22) − J(X)) / J(STC22)

区間は、ネットワークを単位とする対応ブートストラップの95%区間である。反復は2000回、seed は 12345 である。相対差の分母は J(STC22) で、正なら X の費用が低い。

08届かなかったこと

exact 定理は十分条件で、必要条件ではない。フォールバックが作れないことは「安定化できない」を意味しない。その場合の答えは不確定である。十分条件では安定化できることを証明できない、というだけである。

docs/theory/T2_sufficient_baseline.md:33@bb1fa91

empirical 評価の判定は、事前登録した開発上の決定規則である。5つの重みは同じネットワークを共有し、多重性の補正をしていない。一般的な優位を主張するものではない。

prereg/Headroom_2026-10-29.md:67@bb1fa91

評価に使ったネットワークのうち、random_kin は4件だけである。ランダムな配線の BN にこの結果が当てはまるかは、分かっていない。

exact 証明書の重み w_j は厳密な有理数だが、グラフの深さに対してビット長が指数的になりうる。深いグラフでは、厳密な算術での証明書の計算が重くなりうる。

09読むときの注意

DAG のフォールバック定理は、このラインの新しい結果ではない。Li, Li, Yang（2023）の先行研究にある。このラインは、その定理の新規性を主張しない。

B の5/5は、候補を200個に増やすと、この94ネットワークで費用が下がったことを示す。先読み（A）の0/5は、今回の先読みが STC22 より低費用にならなかったことだけを示す。先読み一般が役に立たないことは示さない。

平均 Δ は少数のネットワークに引っ張られている。中央値 Δ も合わせて読む。

4230/4230 の完走は、この94ネットワークでのことである。フォールバックのないモデルが一般にどれだけあるかは、この評価からは分からない。
