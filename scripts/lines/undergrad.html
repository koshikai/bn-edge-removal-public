卒論・学会ライン

実験。時間入力の仕様（単調性・休薬期間）の下で、辺の除去を Q 学習で選ぶ。Cortical 32状態と Wnt5a 128状態を全数評価する。

01問い

empirical 問いは「時間入力の仕様を守りながら、到達と維持を両立できるか」である。時間入力の仕様とは、辺の除去をいつ始め、いつやめてよいかの決まりである。ここでは単調性と休薬期間の2つを扱う。

到達と維持は、有限時間の動作仕様として書く。時刻 H までに目標集合へ初めて到達し、その後時刻 T まで目標集合の中に留まる。これを初到達後維持と呼ぶ。

結果は、Cortical の全32初期状態と Wnt5a の全128初期状態で、5シードすべてが入力違反なしに初到達後維持に成功した。介入なしでも、Cortical は 32 状態中 10 状態、Wnt5a は 128 状態中 108 状態が同じ基準で成功する。介入が必要だった初期状態は、その差の分である。

03介入の意味

介入は辺の除去である。辺 k を除去する入力を uk ∈ {0, 1} とする。除去した辺は、更新式の中で入力の値を固定する。活性化の辺と抑制の辺で、固定する値が違う。

活性化入力：(¬u) ∧ x　　抑制入力：u ∨ ¬x

具体例を書く。遺伝子 A が遺伝子 B を活性化する辺を考える。u = 1 なら (¬u) ∧ x は x によらず 0 になり、A が発現していても B への活性化は届かない。抑制の辺なら u ∨ ¬x が 1 になり、抑制が外れた状態と同じになる。u = 0 なら、どちらの式も元の入力 x、¬x に戻る。

制御費用は除去した辺の本数に比例する。rcontrol(ut) = −cedge‖ut‖1 である。

他のラインとの違い。Paper 1 の主比較は、各時刻に NoOp か辺1本を選ぶ。このラインは複数の辺を同時に除去でき、その本数に費用がかかる。さらに、除去の時間的な並びに仕様がつく。

04実験の手順

exact 入力仕様は信号時相論理（STL）で書き、学習が扱えるフラグ状態に落とす。手順は次の順である。

  1. 仕様を書く。単調性は、除去を始めた辺は戻さないことを全期間で求める。休薬期間は、除去した辺を τ ステップのあいだ再除去しないことを求める。tex/zemi2/main.tex:302@4b5277atex/zemi2/main.tex:303@4b5277a
  2. フラグの更新式を決める。単調性は h ∨ u で更新し、初期値は 0 である。休薬は、u = 1 なら τ、それ以外は max(0, h − 1) で更新する。tex/zemi2/main.tex:320@4b5277a
  3. 違反関数を決める。単調性では、h = 1 かつ u = 0 のときを違反とする。tex/zemi2/main.tex:510@4b5277a
  4. 行動マスキングを置く。行動を選ぶ前に、各辺のフラグとその辺への行動を照らし合わせ、仕様に違反する行動を選択肢から外す。マスクは BN の遷移を予測しない。tex/zemi2/main.tex:331@4b5277a
  5. 監視状態を3値で持つ。s = 0 は未到達、s = 1 は初到達後に維持中、s = 2 は維持の失敗が確定、を表す。監視状態は離脱を禁じない。軌道の状況を記録するだけである。tex/zemi2/main.tex:365@4b5277atex/zemi2/main.tex:377@4b5277a
  6. 学習する。ε-greedy で、許容行動の集合 U(ht) の中から探索する。更新式の最大化も次状態の許容行動 U(ht+1) に限る。軌道が仕様を満たす（sT = 1）とき、最終遷移の報酬に終端ボーナス R_goal を足す。tex/zemi2/main.tex:404@4b5277atex/zemi2/main.tex:446@4b5277a
  7. 評価する。学習後の貪欲方策を全初期状態から動かす。5シード（11–15）で繰り返す。比べる基準として、介入なしでの成功数も数える。tex/zemi2/main.tex:518@4b5277a

初期状態は全数を使い、標本は取らない。

05指標の定義

exact 成功率は、次の3条件をすべて満たす初期状態の割合である。分母は初期状態の数（Cortical 32、Wnt5a 128）である。

  • 初到達が時刻 H 以下である。
  • その後 T = 10 まで目標集合を出ない。
  • 入力仕様に違反しない。

成功は監視状態 sT = 1 と同じで、sT = 2 なら失敗である。違反は、違反関数が真になる時刻が1つでもあることを指す。

目標別の厳密値では3つの量を使う。単調性で失う数は、制約なしで制御できる初期状態の数から、単調性を課したときの数を引いたものである。分母は各目標の初期状態数である。j* は、到達後に除去を許すステップ数 j を動かしたとき、制御できる状態が制約なしと同じになる最小の j である。t_off* は、治療の終了時刻 t_off を 0〜10 で動かしたとき、同じになる最小の t_off である。

単調性の代償が出るのは哺乳類細胞周期だけである。単調性は、到達後に除去を加えることは許すが、到達前に除去を戻すことを許さない。哺乳類細胞周期では、単調性を全期間に課しても到達前だけに課しても、制御できる状態は 187,392 になった。到達後だけに課すと 268,096 のままだった。だから代償 80,704 は、すべて到達前に除去を戻す必要から来る。この代償は、到達後の除去を禁じて失う 4,464 よりずっと大きい。他の9目標では、どの位相に課しても単調性の代償は 0 だった。

08届かなかったこと

閉じた 卒論版は、入力仕様をハード制約ではなく違反ペナルティとして扱った（soft constraint）。だから厳密な充足を保証しない。報酬は安定化・制御・違反の3項からなり、違反のときに罰を与える。学会版（資料2）では、違反行動をマスクで選択肢から外す方式に替えた。

09読むときの注意

成功率 100% は、2つの小さなモデルと条件1通りでの empirical な結果である。介入なしでも Cortical は 32 状態中 10 状態、Wnt5a は 128 状態中 108 状態が成功する。100% をすべて学習の寄与として読まない。

目標別の表（表3）は exact で、学習もシードも含まない。表2とは型が違うので、同じ物差しで比べない。

表3は10目標、H = 7、T = 10 の1条件だけの結果である。モデル一般の性質ではない。

資料1と資料2は初期状態、エピソード数、仕様の扱いが違う。2つの資料の数値を混ぜて読まない。このページの主結果は資料2（tex/zemi2）の値である。
