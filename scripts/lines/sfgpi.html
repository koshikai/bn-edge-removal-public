SF + GPI

探索。厳密な辺除去の下で、複数の報酬に対する方策の再利用が成り立つか。MAPK 1モデル、除去可能辺10本、累積4本まで。

exploratory設定は exactMAPK 1モデル多重比較補正なし

01問い

exploratory このラインの問いは、方策の再利用が報酬を変えても効果を保つかである。一度学んだ方策群を、別の目標や別の介入価格の下でそのまま使い回せるか。使い回したとき、到達率、報酬、計算の総費用は許容できるか。

道具は2つある。後継特徴（successor features, SF）は、方策ごとに将来の特徴の期待値を持つ。報酬が特徴の線形和なら、新しい重み w との内積で価値を出せる。一般化方策改善（generalized policy improvement, GPI）は、複数の方策の価値の最大値をとって行動を選ぶ。

主張の中心は厳密な辺除去の下での多報酬の方策再利用である。SAT と Trap Space の証明書は構造の補助か強い比較相手として使う。SF が SAT による直接制御に勝つことは主張しない。

02設定

exact 評価するモデルは Grieco らの MAPK ブーリアンネットワーク1つである。53ノードのうち外部入力が4、非同期に更新する内部ノードが49ある。除去できる辺は極性制約つきの10本で、同時に切れるのは4本までである。1回の制御判断で切り替えるのは1本までとする。

03介入の意味

exact 辺 i→j への介入は、終点 j の更新関数 f_j だけを置き換える。置き換え先は、f_j の中の x_i に定数 c を代入した関数である。x_i の値、f_i、j 以外のノードの更新関数は変わらない。x_i はほかの終点には元どおり作用する。ノード i を固定する操作ではない。

f_j′(x) = f_j(x) |x_i = c　（活性化辺は c = 0、抑制辺は c = 1）

MAPK では、この介入を符号付き辺特異的ブーリアン介入（signed edge-specific Boolean intervention）と呼ぶ。活性化辺には0を、抑制辺には1を代入する。つまり符号つきのリテラルを偽にする。抑制辺の4本は、抑制が常にかかる状態になる。10本中7本は、単独で切ると終点が定数0になる。

仮の例で書く。f_j = x_i OR x_k で、i→j が活性化辺なら、c = 0 を代入して f_j′ = x_k になる。f_j = x_k AND NOT x_i で、i→j が抑制辺なら、c = 1 を代入して f_j′ = 0 になる。後者では、抑制辺を切ると終点が定数になる。この例はモデルの実際の規則ではなく、式の読み方を示すためのものである。

他のラインとの違い。非同期 BN のラインは、NOT の下でもリテラル0を代入する。このラインは抑制辺に1を代入する。どちらも「辺の除去」と呼ばれるが、抑制辺での意味が違う。数値を並べて優劣を言わない。

05指標の定義

exact 到達率は、目標の Trap Space に達した試行の割合である。分母は手法ごとの試行数で、01 では 1,920 である。率の差はパーセントポイントで書く。

割引報酬は、03 の定義では12判断の有限和で、割引率は γ = 0.9 である。

G = Σt=0..11 γt rt　（γ = 0.9）

報酬 r_t は、8つの事象の特徴に報酬の重みを掛けた線形和である。だから新しい報酬は、既知の事象の基底の組み合わせになる。全く新しい生物学的事象への転移ではない。表2の割引報酬は手法ごとの平均で、分母は表1の到達率と同じ試行数である。01 の表が 03 と同じ12判断の打ち切りを使うかは、このページの資料では確かめていない。

費用込み平均報酬は、介入の費用を差し引いた報酬の平均である。SF+GPI はこの指標で、表に並ぶ手法の中で最良だった。生の到達率では最良ではない。

09読むときの注意

「SF+GPI が SAT より優れる」とは読まない。到達率では SAT を使う直接制御が上である。SF の主張は、費用込みの報酬で見た方策の再利用である。

GPI 対平均の+13.44ポイントは、平均という弱い比較相手に対する差である。最良の単一方策との比較ではない。

元方策は固定の追跡方策で、最適化した方策ではない。新しい報酬は既知の4目標の組み合わせで、新しい目標を見つけたことを示さない。

ここでの辺除去は、抑制辺に1を代入する定義である。「生物学的な辺のノックアウト」とは読まない。

型の整理。モデル、介入、指標の定義は exact である。到達率、報酬、検定の結果は exploratory として読む。
