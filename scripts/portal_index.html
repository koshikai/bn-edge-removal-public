Research demo

Boolean Network Edge Removal

ブーリアンネットワークの安定化制御で、どの辺をいつ取り除くかを強化学習（Q-learning）で求める研究について、 ブラウザで動くデモと公開コードを置いています。

GitHub ↗

Dashboards

  1. 01 到達可能性の検証 →

    すべての初期状態から目標状態へ到達できるかを、単調性や休薬の制約のもとで厳密に検証し、 遷移の証拠（Witness）を表示します。

  2. 02 強化学習の実験結果 →

    Q学習で得た辺除去方策の学習曲線、状態の軌道、辺を除去する時刻の推移を確かめられます。

  3. 03 ネットワーク構造の可視化 →

    対象のネットワークについて、活性化と抑制の辺を含むグラフ構造を表示します。

About

ダッシュボードは WebAssembly（Pyodide）でブラウザ内の Python を動かしています。 サーバー側の計算はありません。初回は Python の読み込みに時間がかかることがあります。
