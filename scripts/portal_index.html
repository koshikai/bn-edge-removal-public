時間入力制約下におけるブーリアンネットワークのエッジ除去制御

Edge Removal Control of Boolean Networks under Temporal Input Constraints

越 海斗（Kaito Koshi）

  • デモ ↓
  • GitHub ↗
  • 引用

概要　遺伝子調節ネットワークを表すブーリアンネットワークに対し、遺伝子間の相互作用（エッジ）を一時的に除去して、状態を目標集合へ到達させ、その後も留める制御を考える。本研究では「一度除去したエッジは元に戻せない」（単調性）、「除去した後の一定期間は同じエッジを除去できない」（休薬期間）という時間的な入力制約を課し、これを満たす制御方策を Q 学習で獲得する。入力制約に違反する行動は行動マスキングで選択肢から除外するため、学習中も含めて違反は生じない。Cortical Development Model と Wnt5a モデルの全初期状態について、5 seed のすべてで期限内の到達とその後の維持に成功した（成功率 100%）。

  • 01

    フラグ状態

    入力制約の判定に必要な介入履歴を、エッジごとのフラグに記録する。BN の状態だけでは判断できない履歴を、Q 学習の状態に含められる。

  • 02

    行動マスキング

    フラグから、各時刻に許容される行動の集合が決まる。違反する行動を候補から除外するため、探索中も入力制約は破られない。

  • 03

    監視状態

    目標仕様の進行を「未到達」「到達後維持中」「失敗確定」の 3 値で記録し、到達前の状態と離脱後の状態を区別する。

01ブーリアンネットワークとエッジ除去制御

遺伝子の発現は、他の遺伝子による活性化や抑制を受けて変化する。この相互作用を表したものを遺伝子調節ネットワークと呼ぶ。本研究では、各遺伝子の発現状態を ON（1）と OFF（0）の二値で表すブーリアンネットワーク（BN）を用いる。時刻 t の状態 xt は n 個の二値を並べたベクトルであり、全遺伝子を同期的に更新する。

xt+1 = f(xt)

状態空間は有限（2n 通り）であるため、任意の初期状態から出発した軌道は、固定点または周期アトラクタに収束する。ただし、収束先が望ましい状態であるとは限らない。

BN の制御では、外部入力によってノードの状態を直接操作する手法が一般的である。これに対しエッジ除去制御では、遺伝子間の相互作用（エッジ）を一時的に阻害する。遺伝子の発現そのものではなく信号伝達経路に介入するため、副作用の少ない治療戦略につながる可能性がある。

エッジ j → i を除去すると、遺伝子 i の更新関数は遺伝子 j の状態に依存しなくなる。具体的には、活性化入力 x(j) を 0 に、抑制入力 ¬x(j) を 1 に置き換える。除去可能なエッジはあらかじめ定めておき、各時刻にどのエッジを除去するかを表す二値ベクトル ut を制御入力とする。

xt+1 = f̃(xt, ut),　　uk,t = 1 ⇔ 時刻 t にエッジ k を除去する

02時間的な入力制約

医療応用では、介入の時間的な構造や頻度に制約がある。本研究では、生物学的応用で重要となる次の 2 つの入力制約を扱う。いずれも、時間に関する仕様を記述する信号時相論理（STL）の式で表せる。

単調性

CRISPR-Cas9 によるゲノム編集のように、一度行った操作を元に戻せない場合を表す。あるエッジを除去したら、以後もそのエッジを除去し続けなければならない。

充足する例001111
違反する例011000除去した後に復帰させている

休薬期間

抗がん剤の投与スケジュールのように、介入後に回復期間が必要な場合を表す。あるエッジを除去したら、その後 τ ステップは同じエッジを除去できない（本研究では τ = 2）。

違反する例1休1000休薬期間中に除去している

03制御目的

目標は単一の状態ではなく、望ましい状態の集合 𝒳goal である。本研究では、この集合への安定化を有限の時間区間で次のように定める。

  • 到達期限 H：時刻 H までに目標集合へ初めて到達する。
  • 終了時刻 T：初到達の時刻から時刻 T まで、目標集合の外に出ない。
  • 入力制約：この間を通して、単調性または休薬期間を満たす。

これらをすべて満たし、かつ除去エッジ数の総和（介入数）J = Σt ‖ut‖1 が小さい制御方策を求める。目標集合に到達した後に離脱した場合は、再び到達しても失敗とみなす。

04問題の難しさ

この問題の難しさは、入力制約が過去の入力に依存することにある。同じ状態 xt であっても、2 ステップ前に同じエッジを除去したかどうかで、現在そのエッジを除去してよいかが変わる。したがって、xt だけを状態とする Q 学習では、入力制約の判定に必要な情報が不足する。

目標仕様にも同様の問題がある。目標集合の外にある状態でも、まだ一度も到達していない場合と、到達後に離脱して失敗が確定した場合とでは意味が異なる。

05提案手法

フラグ状態による状態拡張

入力制約の判定に必要な履歴だけを、エッジごとのフラグ hk,t に記録する。入力履歴全体を保持する必要はない。

単調性休薬期間（τ）
フラグの意味過去に除去したことがあるか（0/1）再び除去できるまでの残りステップ数（0〜τ）
更新則h ← h ∨ u除去したら τ、除去しなければ 1 減らす（下限 0）
違反となる行動h = 1 のときに除去しないh > 0 のときに除去する

行動マスキング

フラグから、違反となる行動を判定できる。単調性では hk = 1 のエッジを「除去する」に固定し、休薬期間では hk > 0 のエッジを「除去しない」に固定する。それ以外のエッジは自由に選べる。ε-greedy による探索でも Q 値が最大の行動の選択でも、この許容行動集合の中から行動を選ぶ。許容行動集合は常に空ではない（単調性では現在のフラグと同じ行動、休薬期間では何も除去しない行動が許容される）。

これにより、入力制約の違反はペナルティで抑えるのではなく、構成的に生じなくなる。学習中も違反は 0 である。

先行研究 [1] では、違反にペナルティ（負の報酬）を与えて入力制約の充足を促していたため、違反しないことは保証されなかった。

監視状態

目標仕様の進行状況を st ∈ {0, 1, 2} で記録する。

  • 0：目標集合に未到達
  • 1：初到達後、目標集合内に留まっている
  • 2：失敗が確定した（到達後に離脱した、または期限 H までに到達しなかった）。一度 2 になると以後も 2 のままである

終了時刻に sT = 1 であれば成功である。監視状態は離脱を禁止するものではなく、観測された軌道の状況を記録する。

Q 学習と報酬設計

Q 学習の状態には、BN 状態・フラグ状態・監視状態の組 (xt, ht, st) を用いる。報酬は次の 3 項の和とする。

  • 目標集合内にある各ステップ：+rstep
  • 除去したエッジ 1 本あたり：−cedge（介入数の低減を促す）
  • 成功してエピソードを終えた場合（sT = 1）のみ：+Rgoal

一度離脱すると st = 2 が続くため、再到達しても終端報酬は得られない。この報酬設計により、初到達後の維持を促す。

06計算例と結果

2 つのモデルの全初期状態について、5 seed（11〜15）のすべてで成功した。入力制約の違反と目標集合からの離脱は、いずれも 0 であった。

計算例 1：Cortical Development Model（単調性）

大脳皮質の領野形成に関わる 5 遺伝子のモデル [2] である。目標集合は、胎生 10.5 日における前極（Fgf8・Pax6・Sp8 が ON）と後極（Emx2・Coup-tfi が ON）の発現パターンからなり、いずれも無制御ネットワークの固定点である。

  • 除去可能エッジ：6 本
  • 入力制約：単調性
  • 到達期限と終了時刻：H = 5、T = 10
  • 学習：15,000 エピソード。学習時の初期状態は全 32 状態を巡回させる
  • 報酬：rstep = 2、Rgoal = 80、cedge = 1
  • 無制御の場合：32 状態中 10 状態のみ成功

計算例 2：Wnt5a モデル（休薬期間）

メラノーマの転移に関わる Wnt5a シグナル伝達経路の 7 遺伝子モデル [3, 4] である。無制御ネットワークは 4 つの固定点をもち、そのうち x(7) = 1 である 2 つを目標集合とする。

  • 除去可能エッジ：8 本
  • 入力制約：休薬期間（τ = 2）
  • 到達期限と終了時刻：H = 7、T = 10
  • 学習：24,000 エピソード。学習時の初期状態は全 128 状態を巡回させる
  • 報酬：cedge = 2（その他は計算例 1 と同じ）
  • 無制御の場合：128 状態中 108 状態が成功。時刻を含む状態での全探索により、休薬期間を満たしたまま全 128 状態で成功可能であることを確認している

07手法の限界と注意点

  • 目標集合での維持は保証しない。入力制約は行動マスキングにより必ず満たされる。一方、目標集合での維持は報酬によって促しているだけで、保証はない。本計算例で離脱が 0 であったのは結果である。
  • Q テーブルに時刻を含めていない。到達期限 H と終了時刻 T の判定には時刻を用いるが、Q テーブルの状態は (x, h, s) のみである。同じ状態では残り時間によらず同じ行動を選ぶため、有限ホライズン問題としての最適性は一般に保証されない。
  • Wnt5a の除去コストは評価と同じ seed で選定した。cedge = 2 の選定に評価と同じ 5 seed を用いたため、独立な検証ではない。
  • 介入数の最小化は保証しない。除去コストは介入を減らす方向に働くが、介入数が最小であることや、到達後に介入が 0 になることは保証しない。
  • 先行研究とは複数の条件が異なる。[1] とは初期状態集合（Wnt5a で 96 → 128 状態）、除去コスト、一部の学習条件が異なるため、結果の差を一つの変更だけに帰することはできない。
  • 対象ネットワークは小規模である。5 遺伝子と 7 遺伝子であり、Q テーブルで扱える規模にとどまる。

08今後の課題

  • 深層強化学習を用いて、Q テーブルに収まらない大規模ネットワークへ適用する。
  • 単調性と休薬期間の同時考慮など、より多様な時相論理仕様を扱う。
  • 確率的ブーリアンネットワークへ拡張する。

09背景と関連研究

BN は遺伝子調節ネットワークのモデルとして広く用いられており [5]、セミテンソル積を用いた代数的アプローチ [6] により、到達可能性解析や安定化制御の研究が進められてきた。制御手法としては、ノードの状態を直接操作するピン留め制御 [7] や、強化学習を用いる手法 [8] が提案されている。エッジ除去制御と Q 学習による安定化は Li と Li [9] が提案したが、制御入力の履歴に対する制約は扱われていない。

STL などの時間的仕様を強化学習に組み込む研究は、ロボティクスを中心に進められている [10–12]。しかし、これらは主に実数値信号を対象としており、BN のような離散システムへの適用は十分に検討されていない。本研究は筆者らの先行研究 [1] を発展させ、行動マスキングによる入力制約の厳密な充足と、初到達後の維持を求める目標仕様を扱う。
