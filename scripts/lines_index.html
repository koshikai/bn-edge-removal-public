研究ラインは9本ある。どのラインも、ネットワークの状態を見て、どこに介入するかを選ぶ。違いは、何を動かすか、介入をどれだけ保つか、方策をどう作るかにある。

01実験の骨格

どのラインも同じ骨格をもつ。時刻 t の状態 xt と制御入力 ut から、次の状態 xt+1 が決まる。制御入力はどの辺を切るかを表す 0/1 の並びである。

評価は3つに分ける。

  • 到達

    期限 H までに目標集合へ入るか。

  • 維持

    入ったあと、終了時刻 T まで目標集合を出ないか。一度出たら、戻っても失敗とする。

  • 費用

    切った辺の数。到達と維持が同じなら、少ないほうがよい。

02操作は3種類

介入の仕方は3種類ある。大半のラインは辺を切る。図は説明用の4節点の例で、どのラインのモデルでもない。青い点の流れは、信号が辺を伝わる様子を表す。

辺を切る

依存を外す。x4 ⊣ x1 を切ると、x1 は x4 を見なくなる。

節点の値を固定する

旧 C2D の Axis A だけが使う。x3 を 1 に固定する。

通信リンクを切る

ロボット群のライン。R1 が持つ情報が隣へ広がる。R1–R2 のリンクを切る。

4節点の例の更新則。辺の例は x1' = not x4, x2' = x1, x3' = x2, x4' = x3（初期状態 0000）。ロボットの例は、自分か、リンクがつながった隣が情報を持てば持つ（初期は R1 だけ）。ロボットの例は、リンクを1本切ると全員に届くまでが長くなる様子だけを見せる。ロボット群ラインの実際のモデルとは違う。

03保持の3通り

切った辺をいつまで切ったままにするかで、ラインが分かれる。色のついた区間が介入している時刻である。

1遷移だけ切る
本体の論文
T ステップ保持
非同期ライン（T = 3 の例）
不可逆に切る

  • 1遷移だけ切る：その遷移にだけ使い、次の遷移には残らない。毎回選び直す。
  • T ステップ保持：観測のたびに mask と保持時間 T を選ぶ（▾ が観測の時刻）。T ステップ同じ mask を使い、次の観測で戻せる。斜線は別の mask。
  • 不可逆に切る：一度切ったら最後まで戻らない。

04同期と非同期

同じ5節点のネットワーク（Cortical、介入なし）を2通りに更新する。同期では全節点が同時に変わる。非同期では、乱数で1節点を選び、その節点だけを更新する。どちらも、どの節点も変わらない状態（固定点）に入ったら止める。

05方策の作り方4つ

どの辺をいつ切るかを決める規則を方策と呼ぶ。作り方は4つある。保証の強さはそれぞれ違う。

  • exact

    全状態探索

    入力
    更新則、目標集合、H と T、入力の制約
    出力
    状態ごとの成否と、成功させる入力列
    保証
    調べた条件の中では成否が確定する。状態数が多いと計算できない
  • 表形式 Q 学習

    Q 表を学習する

    入力
    状態（必要なら介入履歴のフラグと監視状態を含める）と報酬
    出力
    状態と行動ごとの Q 値の表、そこから選ぶ方策
    保証
    行動マスキングを使えば入力制約の違反は起きない。到達と維持は評価で確かめる
  • 閉じたライン

    DQN

    入力
    状態ベクトル
    出力
    ニューラルネットで近似した Q 値と、そこから選ぶ方策
    保証
    なし。Q 表を関数近似に置き換えた路線で、2026-10-27 に閉じた
  • SF + GPI

    方策を組み合わせて再利用する

    入力
    学習済みの複数の方策の successor features と、新しい報酬の重み
    出力
    各状態で、方策群の中から最も価値の高いものを選ぶ方策
    保証
    方策群の中から価値の高いものを選ぶ（GPI）。近似誤差があると、その分だけ弱まる

07触って確かめる

Cortical モデル（5節点、同期更新）で、切る辺を選んで結果を見る。ui = 1 で辺 i を切る。選んだ辺は t = 0 から 10 まで毎ステップ切り続ける。目標集合は 10101 と 01010 で、どちらも介入なしで固定点である。

成功は、H = 5 以内に初めて目標集合へ入り、その後 T = 10 まで目標集合を出ないこと。切る辺を増やすほど成功が増えるわけではない。「全部切る」と「辺3と6を切る」を比べてほしい。

本体 Paper 1 確認研究

  
    
    
  • 対象は 243 family。目的関数は H = 20 の occupancy。即時の単一辺除去（matched-k1）。遷移数の予算を揃えて比べた。
    • 
    
  • 主結果は ΔAUC +0.01933、95% CI [+0.01259, +0.02662]。
    • 
    
  • 予算ごとの差は +0.020、+0.029、+0.041、+0.053、-0.024、-0.085 と符号が変わる。
    • 
    
  • 最大予算で oracle の 10% 以内に入った割合は、offline が 70.5%、学習器が 8.6%。
    • 
  

  
注意：「Q 学習が上」という主張ではない。宣言した予算範囲の平均で、oracle との差が小さい、という主張である。

09数字の読み方

  
    
    
  • exact全状態と全入力を調べて得た値。乱数を含まない。条件を変えると値も変わる。
    • 
    
  • empirical学習や乱数を含む実験で測った値。seed の数と分母を一緒に書く。
    • 
    
  • exploratory仮説を先に固定せずに探った結果。モデルが1つだけ、多重比較補正なし、などの制限がある。
    • 
  

  
型の違う数字は、同じ表に並べない。確かさの違う値を、同じ物差しで比べてしまうからである。

  
「確認研究」は、比較の範囲を先に宣言してから確かめた研究を指す。「閉じた」「一部閉鎖」は、そのラインの実験を止めたことを示す。
